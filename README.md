# OpenLLM

OpenLLM is a high-performance, premium AI platform that aggregates distributed intelligence from multiple LLM providers into a single, unified interface and API.

## Features

- **Unified API Gateway**: Single endpoint for accessing various LLM providers.
- **Smart Routing**: Intelligent selection of the best available model based on performance and availability.
- **Neural Interface**: Futuristic, glassmorphic chat UI with real-time streaming and markdown support.
- **Persistent Memory**: Locally stored chat history with advanced session management.
- **Zero Configuration**: Easy one-click startup for a seamless experience.

## Getting Started

### Quick Start (Windows)
Simply run the `run.bat` file in the root directory.

### Manual Setup
1. Install dependencies: `npm install`
2. Start the development environment: `npm run dev`

## Architecture

OpenLLM is built with a modern tech stack designed for speed and reliability:
- **Frontend**: React, Tailwind CSS, Vite, Lucide Icons.
- **Backend**: Node.js, Express, SQLite (via Better-SQLite3).
- **Security**: AES-256 encryption for API keys, secure session portals.
